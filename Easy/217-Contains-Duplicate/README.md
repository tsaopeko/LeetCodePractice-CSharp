## 💡 Learning Notes

### 1. Two Sum

- 練習使用陣列與迴圈尋找符合條件的兩個數字。
- 理解暴力解法與 Dictionary 解法的差異。
- 學習使用 Hash Table 加速資料查找。
- 比較不同解法的時間複雜度。

### 2. Contains Duplicate

- 練習使用雙層 `for` 迴圈判斷陣列中是否存在重複元素。
- 學習使用 `HashSet<int>` 記錄已經出現過的數字。
- 理解如何透過 `Contains()` 判斷元素是否存在。
- 比較暴力解法與 HashSet 解法的時間及空間複雜度。
