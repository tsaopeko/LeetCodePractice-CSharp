# LeetCode 36 - Valid Sudoku（有效的數獨）

## 題目說明

給定一個 `9 x 9` 的數獨棋盤 `board`，判斷目前棋盤是否有效。

有效棋盤必須符合以下三個條件：

1. 每一列（Row）不能出現重複的數字 `1~9`。
2. 每一行（Column）不能出現重複的數字 `1~9`。
3. 每個 `3 x 3` 的九宮格（Sub-box）不能出現重複的數字 `1~9`。

空白格以 `'.'` 表示，不需要進行檢查。

注意：只需要判斷目前棋盤是否符合規則，不需要判斷棋盤是否有解。

## 解題思路

使用 `HashSet<char>` 儲存已經出現過的數字，利用 `HashSet.Add()` 的回傳值判斷是否有重複。

`HashSet.Add()`：
- 回傳 `true`：成功新增，代表該數字尚未出現。
- 回傳 `false`：新增失敗，代表該數字已經存在。

### 1. 建立 HashSet

使用三種 HashSet 分別管理不同範圍：

- `rows`：紀錄每一列出現過的數字。
- `cols`：紀錄每一行出現過的數字。
- `boxes`：紀錄每個九宮格出現過的數字。

在開始檢查棋盤之前，先初始化所有 HashSet。

### 2. 遍歷棋盤

使用兩層迴圈遍歷整個棋盤：

- 外層迴圈負責取得列索引 `row`。
- 內層迴圈負責取得行索引 `col`。

遇到 `'.'` 時直接使用 `continue` 跳過。

### 3. 判斷九宮格位置

透過整數除法計算目前格子所屬的九宮格：

```csharp
int boxRow = row / 3;
int boxCol = col / 3;
```

例如，當目前位置為 `(4, 5)`：

```text
boxRow = 4 / 3 = 1
boxCol = 5 / 3 = 1
```

因此該位置屬於九宮格陣列中的 `[1, 1]`。

### 4. 同時檢查三種規則

使用 `HashSet.Add()` 同時檢查列、行與九宮格。

只要其中一個 HashSet 新增失敗，就代表出現重複數字，直接回傳 `false`。

如果完整遍歷棋盤都沒有發現重複，最後回傳 `true`。

## 時間與空間複雜度

### 時間複雜度

- 使用兩層迴圈遍歷棋盤。
- 每個格子最多進行三次 `HashSet.Add()`。
- `HashSet.Add()` 平均時間複雜度為 O(1)。

一般化為 N x N 棋盤時：

**時間複雜度：O(N²)**

### 空間複雜度

使用多個 HashSet 儲存已經出現過的數字：

- rows：O(N²)
- cols：O(N²)
- boxes：O(N²)

因此一般化棋盤的額外空間複雜度為：

**空間複雜度：O(N²)**

由於 LeetCode 本題固定使用 9 x 9 棋盤，因此實際上時間與額外空間皆可視為 O(1)。
