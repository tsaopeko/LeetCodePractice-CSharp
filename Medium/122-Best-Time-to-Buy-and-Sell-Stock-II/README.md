# LeetCode 122 - Best Time to Buy and Sell Stock II

## 題目說明

給定一個整數陣列 `prices`，其中 `prices[i]` 代表股票在第 `i` 天的價格。

你可以進行多次股票交易，但必須遵守以下規則：

1. 買進股票之前，必須先賣出手上持有的股票。
2. 同一時間只能持有一股股票。
3. 賣出股票後，可以在同一天再次買進。

請計算能夠獲得的最大總利潤。

## 範例

**Example 1**

```text
Input: prices = [7,1,5,3,6,4]
Output: 7
```

交易方式：

- 第 2 天以 1 元買進，第 3 天以 5 元賣出，獲利 4 元。
- 第 4 天以 3 元買進，第 5 天以 6 元賣出，獲利 3 元。

總獲利：`4 + 3 = 7`

**Example 2**

```text
Input: prices = [1,2,3,4,5]
Output: 4
```

價格持續上漲，可以 1 元買進、5 元賣出，獲利 4 元。

即使將交易拆成多次，累積獲利仍然相同。

**Example 3**

```text
Input: prices = [7,6,4,3,1]
Output: 0
```

價格持續下跌，沒有任何正向漲幅，因此最大獲利為 0。

## 解法：Greedy（貪心演算法）

### 核心想法

由於題目允許進行多次交易，因此不需要只尋找最低買入價格與最高賣出價格。

我們可以比較每天與前一天的價格：

- 如果今天價格高於昨天，就將兩天的價格差加入總獲利。
- 如果今天價格低於或等於昨天，就不進行累加。

也就是說，只要遇到正向漲幅，就將它累加起來。

### C# 程式碼

```csharp
/// <summary>
/// 計算多次股票交易所能獲得的最大總利潤。
/// </summary>
/// <param name="prices">每日股票價格陣列。</param>
/// <returns>可以獲得的最大總利潤。</returns>
public int MaxProfit(int[] prices)
{
    int maxProfit = 0;

    for (int i = 1; i < prices.Length; i++)
    {
        if (prices[i] > prices[i - 1])
        {
            maxProfit += prices[i] - prices[i - 1];
        }
    }

    return maxProfit;
}
```

### 執行過程

以以下陣列為例：

```text
prices = [2,4,7,3,8]
```

逐日比較：

| 比較日期 | 價格變化 | 是否累加 | 累積獲利 |
|---|---:|---|---:|
| 2 → 4 | +2 | 是 | 2 |
| 4 → 7 | +3 | 是 | 5 |
| 7 → 3 | -4 | 否 | 5 |
| 3 → 8 | +5 | 是 | 10 |

最後得到最大總獲利：

```text
Output: 10
```

## 時間與空間複雜度

| 複雜度 | 結果 | 原因 |
|---|---|---|
| 時間複雜度 | O(n) | 只需要遍歷價格陣列一次 |
| 空間複雜度 | O(1) | 只使用固定數量的變數 |

## 學習重點

### 1. Greedy（貪心演算法）

每次遇到價格上漲，就立即將漲幅加入總獲利。

不需要考慮所有可能的買賣組合，而是利用局部最有利的選擇，累積出全域最大獲利。

### 2. 為什麼可以累加相鄰日期的漲幅？

假設價格持續上漲：

```text
prices = [1,2,3,4,5]
```

直接交易：

```text
5 - 1 = 4
```

拆成多次交易：

```text
(2 - 1) + (3 - 2) + (4 - 3) + (5 - 4) = 4
```

兩種方式的總獲利相同。

因此，將連續上漲區間拆成多個相鄰日期的漲幅，不會減少總獲利。

### 3. 與 LeetCode 121 的差異

| 比較項目 | LeetCode 121 | LeetCode 122 |
|---|---|---|
| 交易次數 | 只能交易一次 | 可以交易多次 |
| 核心思路 | 維護最低買入價格 | 累加所有正向漲幅 |
| 時間複雜度 | O(n) | O(n) |
| 空間複雜度 | O(1) | O(1) |

## 總結

這題透過 Greedy 的方式，將多次股票交易問題簡化成相鄰日期的價格比較。

只要今天的價格高於昨天，就將兩者的差額累加到總獲利中。

**重要觀念：在允許多次交易的情況下，累加所有正向漲幅，就能得到最大總利潤。**
